# 間隔タスク

「前回やってから◯日経ったら、また出てくる」タスクだけを扱うアプリ。
シーツ洗濯（14日）、猫トイレ丸洗い（12日）、洗面台掃除（10日）のようなもの。

締切のある単発タスク（書類提出、返却期限）は**扱わない**。
このアプリは通知もバッジも出さないので、開かなければ何も起きない。
締切ものはカレンダーか標準リマインダーに置く。

遅れを責める表現を持たない。遅れの唯一の表現は「並び順が上がること」と
「セクションが変わること」だけで、赤字も超過日数も警告も存在しない。

```
index.html       アプリ本体。これ1つで完結する
seed-tasks.json  16件のひかえ（やり直したいとき用）
```

---

## iPhoneに入れる

`index.html` はHTML・CSS・JavaScriptを1ファイルに収めていて、
外部の読み込みが1つも無い。機内モードでも全機能が動く。

方法は2つある。どちらでもよい。

**A. GitHub Pages に置く（かんたん）**

このリポジトリの Settings → Pages で、Source を `Deploy from a branch`、
ブランチを `main`、フォルダを `/ (root)` にして保存する。
数分後に `https://nakamu2473.github.io/todo/` で開けるようになる。

**B. ファイルをiPhoneに送る**

`index.html` をiCloud Driveかメールで自分に送り、ファイルアプリから開く。

どちらの場合も、開いたら Safari の共有ボタンから
**「ホーム画面に追加」** を選ぶ。以後はアプリとして起動し、Safariの
アドレスバーは出ない。

## 最初の16件

**初めて開いたときに自動で入る。** 何もしなくてよい。

16件すべてが「まだ先」に入り、日付はその日になる。この時点で「いま出てるもの」は
空なので、猫が寝ている画面から始まる。

> 自動で入るのは **保存データがまったく無いとき（＝初めて開いたとき）だけ**。
> 自分で全部消して0件にした場合は、開き直しても入り直さない。
> ただしSafariのデータ消去などで保存データごと消えると「初めて」に戻るので、
> そのときは16件が入り直す。

### すぐ出したいものを決める

全部を一度に出すと初日で心が折れるので、**最初は3〜5件だけ**にする。
行の右端の `…` から編集を開き、「さいごにやった日」を過去の日付に直す。
その日から間隔日数が経つと「いま出てるもの」に出てくる。

最初に出すものの候補：猫トイレ掃除（8日）、1Fるんばちゃ（6日）、
洗面台掃除（10日）、買い出し（7日）。

2週間くらい使ってから、間隔の数字を実感に合わせて直すとよい。

### やり直したいとき

`seed-tasks.json` に同じ16件が入れてある。データ欄の「読み込む」に貼れば
いつでもこの状態に戻せる。こちらは日付が `2026-08-06` 固定なので、
間隔の短いものは最初から「いま出てるもの」に入る。

## 使い方

| したいこと | 操作 |
|---|---|
| 追加する | 一番上の欄に名前と間隔（日数）を入れて `追加` |
| 完了にする | 行をタップ。「まだ先」へ移る |
| 間違えて押した | 画面下に5秒だけ出る `取り消し` を押す |
| 名前・間隔・最終完了日・絵を直す | 行を長押し、または右端の `…` |
| 消す | 編集画面の `削除` → `消す` |

同じ日に2回タップしても何も起きない。

### 行頭の絵

絵文字ではなく、このアプリの中に描いてある24種類から選ぶ。編集画面の
「アイコン」の並びから選ぶだけで、入力はしない。要らなければ先頭の `—` を選ぶ。

どれも当てはまらないタスクのために、意味を決めていない印を4つ用意してある
（まる・ほし・はな・しずく）。合う絵が無いときは、そのどれかを選んで
「これはあの用事」と決めて使う。

前の版で絵文字を入れていたデータを読み込むと、対応する絵に自動で置き換わる。
対応が無い絵文字は絵なしになるが、**元の絵文字はデータから消えない**ので、
古い `index.html` で開けばこれまで通り絵文字が出る。

## データを控える

保存先は端末の `localStorage` ひとつだけで、同期もバックアップもしない。
iPhoneは長く使っていないサイトの保存データを消すことがあるので、
ときどき控えを取る。

- **書き出す**：データ欄の `書き出す` を押すとJSONがクリップボードに入る。
  メモアプリなどに貼って残しておく。
- **読み込む**：控えたJSONを貼って `読み込む` → `置きかえる`。
  書き出した時点の状態がそのまま戻る。

保存データが壊れていた場合は、空の状態で起動して、その旨を1行で伝える。
**壊れたデータは消さない**。データ欄の「読めなかったデータ」に生の文字列が
出るので、コピーして手で直せる。

## 動作の確認

URLの末尾にハッシュを付けると、確認用の機能が出る。保存はされないので、
ハッシュ無しで開き直せば消える。

| ハッシュ | 動き |
|---|---|
| `#today=2026-09-01` | その日付として表示する |
| `#today=+15` | 15日後として表示する |
| `#selftest` | 日付計算と読み込み検証の自己テストを走らせる |

`#today=` が効いている間は画面の一番上にその旨が出る。`やめる` で戻る。

ブラウザで一通り自動確認したい場合：

```
node /path/to/test.mjs      # Playwright が要る
```

実機のSafariでしか見られないもの（セーフエリア、ホーム画面からの起動、
VoiceOver、日付ピッカーの見た目）は手で確認する。

## 初版に入れていないもの

タグ / 優先度 / サブタスク / メモ欄 / 統計・グラフ / 連続記録 / 検索 /
複数リスト / 手動の並び替え / 同期 / 通知 / アーカイブ

読み込みは知らないフィールドをそのまま保持するので、後から項目を足しても
古いデータが欠けることはない。
